# Panduan Demo Aplikasi

## 1. Tujuan Demo
Menjelaskan cara kerja Aplikasi Pengelolaan Data Putusan Pengadilan.

## 2. Fitur yang Akan Ditampilkan
1. Menampilkan data putusan.
2. Menambahkan data putusan.
3. Mencari data berdasarkan nomor perkara.
4. Menghapus data putusan.
5. Mengurutkan data menggunakan Insertion Sort.
6. Menampilkan statistik putusan.
7. Menampilkan riwayat aktivitas melalui Audit Log.

## 3. Persiapan Demo
- Java JDK 17
- Maven
- Repository proyek

## 4. Alur Demo
Demo dilakukan dengan menjalankan aplikasi, menampilkan data, mencoba fitur pengelolaan data, kemudian menunjukkan hasil pengurutan dan riwayat aktivitas.

## 5. Catatan
Dokumentasi ini akan diperbarui setelah seluruh fitur selesai diintegrasikan dan diuji.
