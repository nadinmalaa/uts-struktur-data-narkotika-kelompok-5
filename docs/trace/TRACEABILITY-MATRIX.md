# Traceability Matrix

## Tujuan
Dokumen ini digunakan untuk menghubungkan kebutuhan fitur aplikasi dengan implementasi dan pengujian.

## Daftar Kebutuhan dan Pengujian

| ID | Kebutuhan/Fitur | Implementasi | Pengujian |
|---|---|---|---|
| REQ-01 | Menyimpan data putusan secara dinamis | DynamicArray | Menguji penambahan dan penghapusan data |
| REQ-02 | Mengelola riwayat aktivitas | Stack dan AuditLog | Menguji operasi push, pop, dan peek |
| REQ-03 | Mengurutkan data berdasarkan lama vonis | Insertion Sort | Memastikan urutan data benar |
| REQ-04 | Mencari data putusan | PutusanManager | Menguji pencarian berdasarkan nomor perkara |
| REQ-05 | Menghitung statistik putusan | PutusanManager | Menguji jumlah data, rata-rata vonis, dan total denda |

## Catatan
Matriks ini akan diperbarui setelah integrasi seluruh fitur dan pengujian akhir selesai.
